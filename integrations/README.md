# Integrations Architecture

Abstract adapters and gateway connectors for external systems:

- `models/`: Provider-agnostic LLM adapters (OpenAI, Anthropic, Gemini, Local).
- `observation/`: Social Observation Layer (SOL) connectors for market research (Planned for Phase 4).
- `platforms/`: Platform Action Layer (PAL) connectors for ad networks and social publishing (Planned for Phase 7).
- `mentor/`: Advisory expert personas for second-opinion consultation.
